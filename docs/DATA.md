[All The Places](https://alltheplaces.xyz/) еженедельно собирает данные из каталогов сетей и распространяет координаты и адреса по [CC0](https://creativecommons.org/publicdomain/zero/1.0/). У игры собственный отбор физических точек по стране `RU`. Карта отражает покрытие исходных каталогов на момент выгрузки. Пометка о визите подтверждает близость к координате ресторана. Время работы и доступность конкретного входа зависят от заведения.

### Обновление

Из корня проекта запустите `python3 scripts/update-venues.py`. Достаточно Python 3.9 или новее. Параметр `--source-dir` принимает папку с четырьмя исходными GeoJSON под именами из таблицы. Параметр `--output` задаёт путь к результату.

Обновление собирает все четыре сети за один проход. Постоянный ключ точки составлен из сети и номера ресторана в исходном каталоге. Исправление адреса и координат сохраняет посещения и таймер игрока. Скрипт отбрасывает служебные и учебные подразделения, записи без адреса, неверные координаты, дубли и противоречивые адреса в одной позиции. Для каждой сети проверяются минимум 650 пригодных записей и сохранение хотя бы 85% прежних идентификаторов, когда файл уже существует. Файл заменяется одним действием после проверки целого набора. При ошибке сохраняется предыдущая версия.

Сценарий GitHub Pages раз в неделю собирает сайт со свежим каталогом. Сбой источника прерывает обновление до публикации. Тот же скрипт работает при локальном запуске. Проверки каталога выполняются командами `node --test tests/data.test.mjs` и `python3 -B tests/data_update_test.py`.

## Меню и изображения

В `public/data/menu.json` для каждой игровой находки записаны название блюда, локальный WebP, ссылка на меню в поле `source` (в игре не показывается, нужна для обновления каталога) и адрес исходной фотографии в `imageSource`. Всего 65 блюд. В каждой сети два легендарных бойца, несколько эпических и редких, остальные обычные. Три стакана колы Бургер Кинга различаются объёмом, и чем больше стакан, тем выше редкость: 0,4 л — обычный, 0,5 л — редкий, 0,8 л — эпический. Стакана 0,3 л в меню сети нет. Фотографии сверены с карточками российских сетей, обрезаны по прозрачным полям и уменьшены для мобильных экранов. Боевые свойства каждого блюда (редкость, роль, здоровье, атака, скорость, приёмы, талант) заданы вручную в `public/js/fighters.js`, числа подобраны перебором (см. [balance](balance/README.md)).

Рулетка выбирает редкость с весами 58 / 27 / 12 / 3 %, а внутри редкости — одно из блюд сети поровну. У каждого легендарного бойца шанс 1,5 % за визит.

Новые блюда ноября 2026 года собраны с сайтов сетей.
- Бургер Кинг закрывает сайт от автоматических браузеров. Он открылся в обычном Chrome с пустым временным профилем, полное меню (266 блюд) взято из хранилища страницы. Фото — прозрачные PNG `orderapp-app-static.burgerkingrus.ru/original/…`.
- Меню «Вкусно — и точка» лежит в `window.__NUXT__` на `/menu`.
- Rostic’s отдаёт меню через `/api/menu/getMenuPassport/…`.
- Додо отдаёт меню через `/api/v5/menu/delivery/…`.

Чего в меню нет или что пришлось заменить:
- Приправы «Сметана и лук» нет ни в одной сети, взята ближайшая — «Прованские травы — сметана» из «Вкусно — и точка».
- Обычного «Биг Кинга» сейчас нет, на фото «Биг Кинг Новый».
- «Додо Клюв» — бумажная маска-клюв из меню Додо, а не еда. Это мемный боец.
- С фото приправы снята промо-наклейка.
- Бургер Бокс, Брауни и приправа могут уйти из меню как сезонные.

Чизбургер Бургер Кинга и Картофель Фри «Вкусно — и точка» из первой версии были убраны, и в старых профилях они превращаются в Чикен Пармезан и Наггетсы с сохранением копий и опыта. Новый Чизбургер — отдельное блюдо с ID `bk-cheeseburger-classic`, старый ID `bk-cheeseburger` по-прежнему ведёт к Чикен Пармезану.

Шесть отдельных соусов Бургер Кинга (Кисло-сладкий, Чесночный, Кетчуп, Горчичный, Карри, 1000 островов) 20 ноября 2026 года заменены одним комбо «6 соусов» из раздела соусов. В профилях их копии и опыт переходят к «6 соусам». Фото комбо: `orderapp-app-static.burgerkingrus.ru/original/catalog/images/dishes/c00137e371f02a7f0377a07ae3083df6.png`. Маффин Три шоколада — из меню Додо. В разделе соусов Бургер Кинга есть и «Соус Сметанно-луковый» — тот самый «сметана и лук», если понадобится.

Права на фотографии и товарные знаки принадлежат соответствующим правообладателям. Условие CC0 относится к геоданным All The Places. Игровая редкость и боевые действия определяются правилами игры.
